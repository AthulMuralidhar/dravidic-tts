# Session notes

This folder is the durable handoff log for BhashaVox.

Create one Markdown file per working date using `YYYY-MM-DD.md`. Each note
should record:

1. the goal for the session;
2. decisions made and why;
3. commits created;
4. commands used to verify the work;
5. open questions, risks, and the next concrete step.

Do not rewrite older notes to make history look cleaner. Add corrections to a
new note or append a clearly dated correction.
