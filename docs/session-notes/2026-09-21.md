# Session note — 2026-09-21

## Goal

Begin an open-source, local-first web application that converts pasted text to
audio, focusing on English, Tamil, and Malayalam.

## User requirements captured

- The primary input is copied and pasted text.
- English, Tamil, and Malayalam are first-class languages.
- Docker and other appropriate tools are acceptable.
- The application will run locally first and should be simple to deploy later.
- Research must be written to `docs/` for later retrieval.
- Session notes must make the work easy to resume.
- Every logical step must end with a Git commit.

## Decisions so far

- Working project name: **BhashaVox**. This is intentionally easy to rename.
- License: Apache-2.0, matching the leading candidate model's permissive
  license.
- Architecture will separate the web/API layer from speech providers.
- Native-script Tamil and Malayalam are MVP scope. Latin-script Tanglish and
  Manglish need an explicit transliteration design and must not be silently
  treated as solved.

## Environment observed

- Python 3.13.7 is installed on the host.
- Node.js 24.6.0 is installed on the host.
- Git 2.49.0 is installed on the host.
- `nvidia-smi` is not available, so the initial runnable path must not assume
  an NVIDIA GPU.
- Docker will pin a compatible Python version rather than relying on host
  Python for ML dependencies.

## Research started

AI4Bharat Indic Parler-TTS currently appears to be the strongest open-source
candidate: it supports English, Tamil, and Malayalam; exposes named voices and
style controls; and is licensed under Apache-2.0. It is a 0.9B-parameter model
and its Hugging Face files require accepting access conditions, so it should
be an optional high-quality provider rather than the only way to boot the app.

Full citations and comparison will be recorded in `docs/research/`.
